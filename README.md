# Celengance - Mobile App (PBL UAS)

Aplikasi Flutter untuk pengolahan keuangan "Celengance" yang dibuat berdasarkan desain Figma PBL UAS.

## 📌 Deskripsi & Features
- Slicing UI dari Figma (Login, Sign Up, Dashboard)
- Integration Global State Management (Provider)
- Responsive Layout & Advanced UI (SliverAppBar / GridView / Stack)
